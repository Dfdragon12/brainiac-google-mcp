# Privacy Policy - BRAINIAC Google MCP

Last updated: 2026-11-11

BRAINIAC Google MCP is a personal, single-user application that runs locally on its owner's computer. It connects to the owner's own Google account (Gmail, Calendar, Drive, Docs and Sheets) through the Google APIs.

## Data accessed
The app accesses only the Google account data that the account owner authorizes through the Google OAuth consent screen.

## Data use
Data is used only to provide the features requested by the owner. It is processed locally on the owner's computer.

## Data sharing and storage
The app does not sell, share or transfer Google user data to third parties, and does not use it for advertising. OAuth tokens are stored locally on the owner's computer and are never published.

## Google API Services User Data Policy
The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
The owner can revoke access at any time at https://myaccount.google.com/permissions
